# Resources

Reference material used in the talks.

| File | What it is |
|---|---|
| [`PLAN.md`](PLAN.md) | The task plan template our agents work from: copy it to `plans/<task>/plan.md`, fill in goals, phases and checkpoints, and have the agent keep it updated as it works. Used in the Day 2 "Planning II" session (plan.md with progress tracking). Source: [pygraphistry `ai/prompts/PLAN.md`](https://github.com/graphistry/pygraphistry/blob/master/ai/prompts/PLAN.md). |
| [`skills/investigation-loop/SKILL.md`](skills/investigation-loop/SKILL.md) | A skill for multi-round alert investigation with an analyst reviewing between rounds: fixed report format (verdict, confidence, evidence, gaps, numbered next steps) and evidence rules. Drop the folder into your agent's skills directory. An example of the skill-shaped planning discussed in Lab 3 and Planning II. |
